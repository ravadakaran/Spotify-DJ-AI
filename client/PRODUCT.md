# DJ Studio

## Platform and scope

Private responsive web application, React JavaScript with the existing Vite client and Express/Socket.IO/MongoDB server. The PRD and `../docs/PROJECT_REQUIREMENTS.md` remain the product authority.

## Users and tasks

Listeners join a lounge, listen to authorized local media, vote, chat/react, enter Soundclash and ask grounded track questions. Hosts and Co-DJs curate and control playback according to server permissions. Hosts manage membership and end sessions. Administrators maintain the catalog and recommendation model. Overview retains recommendations, taste/history, recent lounges and catalog previews.
